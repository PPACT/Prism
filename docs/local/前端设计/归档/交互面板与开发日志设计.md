# 工单：前端交互面板重构与开发日志记录系统

## 一、 背景与目标

当前的前端主要扮演“监控看板”角色，但在实际开发中发现两个痛点：
1. **原生终端体验极差**：直接用黑框跑 `claude`，推理过程（Thought）和工具调用会刷屏并覆盖用户的输入，导致交互极其混乱。
2. **历史上下文易丢失**：开发时间一长，终端滚过的信息就没了。我们需要一种机制，能清晰记录“用户提过什么要求”、“最终产出了什么结果”，方便后续排查是哪次改动引发了 Bug。

**目标**：将前端从“纯监控”升级为“可交互的工作台”，并建立轻量级的自动开发日志。

## 二、 核心功能模块

### 1. 富文本交互面板（类 Cursor Chat）
*   **UI 形态**：固定底部输入框（永不遮挡） + 上方消息流（按时间滚动）。
*   **数据解析与分离渲染**：
    *   中控（Daemon）拉起 `claude -p` 时，必须带上 `--output-format stream-json` 参数。
    *   前端需要解析这个 JSON 流，并根据 `type` 分类渲染：
        *   `thought` / `reasoning`：折叠进灰色面板（默认收起，点击展开）。
        *   `tool_use`：渲染为状态条（例如：`[⚙️ 正在读取 src/login.tsx]` 或 `[✅ 已修改代码]`）。
        *   `text` / `message`：使用 Markdown 渲染（支持代码高亮），作为最终结果展示。
*   **交互逻辑**：用户输入 -> 前端调用 Daemon 接口 -> Daemon 拉起/唤醒对应 Agent -> 返回 Stream 给前端渲染。

### 2. 自动开发日志（Dev Log）
*   **目的**：不需要复杂的版本控制，只需要一本清晰的“流水账”，记录“用户的 Prompt”和“Agent 的最终结果摘要”。
*   **记录方式**：
    *   每次一轮对话结束（Agent 吐完最终结果后），自动往项目内的 `docs/local/开发日志.md` 追加一条记录。
    *   **格式要求**：
        ```markdown
        ### [2026-11-11 15:30:00] 角色: dev
        **🗣️ 用户要求**: 把登录页的按钮改成蓝色。
        **📦 执行结果**: 已修改 `src/login.tsx`，新增 `className="bg-blue-500"`。
        **📄 变更文件**: src/login.tsx
        ```
*   **UI 辅助**：在前端侧边栏或底部 Console 增加一个“开发日志”Tab，实时展示这段 Markdown 渲染后的结果，方便随时回溯。

## 三、 后端改造需求（Daemon 侧）

为了实现上述功能，中控服务（Daemon）需要增加/改造以下接口：

1.  **双向通信接口**：
    *   需要一个 WebSocket 接口（如 `/ws/chat`）或 SSE + POST 组合。
    *   前端通过此通道发送用户的 Prompt。
2.  **进程 stdin 接管**：
    *   Daemon 收到前端 Prompt 后，通过 `subprocess.Popen` 启动 `claude -p --output-format stream-json`，并将 Prompt 写入其 stdin（或者作为启动参数）。
    *   实时读取 `stdout` 的每一行 JSON，原封不动地通过 WebSocket 推给前端。
3.  **日志落盘**：
    *   Daemon 在解析到流结束（如收到 `stop_reason` 或进程退出）时，提取用户的输入和最后一段文本输出，调用现有的文件写入工具，追加到 `docs/local/开发日志.md`。

## 四、 实施步骤建议

*   **Step 1**: 实现 Daemon 的 `POST /chat` 接口（暂用普通 HTTP 轮询或 SSE 返回流），测试底层能否成功调用 `claude -p` 并拿到 JSON 流。
*   **Step 2**: 前端实现 JSON 解析器，把 `thought` 折叠、`text` 渲染、`tool_use` 状态化，完成 UI 面板的静态展示。
*   **Step 3**: 打通双向交互：前端输入框 -> Daemon -> `claude` 进程。
*   **Step 4**: 在 Daemon 侧增加自动写入 `开发日志.md` 的逻辑，并在前端增加一个日志查看面板。
