## 1. 启动与数据源

```text
双击 start_frontend.bat
  → VBS 隐藏启动 → tauri dev
  → App 挂载
      ensureDaemon()：读 <root>/.claude/orchestrator/daemon.json
        ├─ /health 正常 → 复用现有 daemon
        └─ 否则用项目 home 执行 uv run python -m tools.orchestrator.service --serve --port 8765
      → GET /status + GET /tasks
      → 打开 GET /events（状态 SSE）
      → 打开 GET /logs/stream?tail=100（日志 SSE）
```

- daemon 地址每次请求前读 `daemon.json`，端口变化可跟随；读不到时回退 `127.0.0.1:8765`（`src/lib/backend.ts:37-49`）。
- token 从 `<root>/.claude/orchestrator/token` 读入 JS 内存，所有 Bearer 请求自动携带（`backend.ts:101-108,175-179`）。
- 启动超时 20s；React StrictMode 双挂载通过模块级 in-flight Promise 去重（`backend.ts:60-87`）。
- 关闭窗口时 abort 两条 SSE、取消任务重取定时器，并尝试结束由本应用拉起的 daemon（`App.tsx:178-185`）。

| 数据源 | 用途 | 触发方式 |
|---|---|---|
| `GET /status` | daemon + agents 快照 | 启动、命令面板「刷新」、停止失败后回滚 |
| `GET /tasks` | 任务列表 | 启动、SSE snapshot 后去抖重取、停止后 |
| `GET /events` | 状态 SSE：`snapshot` / `heartbeat` / `shutdown` | 启动后常驻，断线退避重连 |
| `GET /logs/stream?tail=100` | 后端日志 SSE：回放 100 行后跟随 | 启动后常驻，断线退避重连 |
| `POST /discover` | 重探存活 + 恢复/清理缓存 + 未注册进程 | 仅「检测 Agent」按钮 |
| `POST /stop` | 停止 daemon 托管 worker | 仅托管 Agent 的「停止」按钮 |

## 4. Agents 面板

### 4.1 表格列

| 列 | 显示规则 | 依据 |
|---|---|---|
| `role` | 角色名；其下以小字显示项目末级目录（有 project 时），悬停看完整路径 | `AgentTable.tsx:46-56`、`format.ts:69-75` |
| `pid` / `pgid` | 原样 | `AgentTable.tsx:57-58` |
| `status` | daemon 原始状态字符串（如 `registered` / `stopped` / `stopping`） | `AgentTable.tsx:59` |
| `alive` | `agent.alive` 为真显示「在线」（绿），否则「已停止」（灰） | `AgentTable.tsx:60-62`、`format.ts:14` |
| `last_heartbeat` | 本地 `YYYY-MM-DD HH:mm:ss` | `AgentTable.tsx:63-68`、`format.ts:43-50` |
| `current_task_id` | 空值显示 `—` | `AgentTable.tsx:69`、`format.ts:16` |
| 操作 | 托管 worker 显示「停止」；外部 Agent 显示「外部进程」 | `AgentTable.tsx:43,70-88` |

### 4.2 按钮与状态

- **检测 Agent**：调用 `POST /discover`；请求中按钮文案「检测中…」并禁用；成功后刷新 Agents、未注册进程，并在 Console 记录：
  `检测 Agent：N 个，在线 M 个；缓存恢复 R，清理 P，未注册进程 W`（`App.tsx:216-237,256-266`）。
- **停止**：仅 `job_id` 非空（daemon 托管）时出现；`pendingRole` 命中时显示「停止中…」并禁用，`alive === false` 时禁用（`AgentTable.tsx:71-79`）。
- **外部进程**：无按钮；悬停提示「外部 Agent，由各自窗口管理；中控无法终止」（`AgentTable.tsx:80-87`）。
- **停止的乐观更新**：先把本地状态置 `stopping` 并记 Console；成功后重取 `/tasks`；失败回滚（重新 `GET /status`），保留错误条与 Console 错误（`App.tsx:188-214`）。
- **空状态**：「暂无 agent」（`AgentTable.tsx:32-36`）。

## 5. 未注册进程（野生进程）

- 仅当 `/discover` 返回的 `wild` 非空时显示；`<details>` 默认展开，标题「未注册进程（N）」（`App.tsx:277-290`）。
- 只在点击「检测 Agent」时更新；不随 SSE 自动刷新。
- 列：`pid` / `cwd` / `cmdline` / `子进程`（`WildTable.tsx:15-64`）。
  - `cwd`、`cmdline` 超宽截断，悬停显示全文；空值显示 `—`。
  - `cmdline` 由 daemon 截断到 300 字符并掩码常见密钥参数/环境变量（`drivers/base.py:14-35`）。
  - `子进程` = `child_pids.length`；列表只展示进程树根，子进程折叠（`drivers/cwd_process.py:1-5`）。
- **只读**：当前没有绑定/解绑按钮，P2 未实现（见 §14）。

### 6.2 任务详情对话框

字段（`TaskDetailsDialog.tsx:62-83`）：

| 字段 | 含义 |
|---|---|
| `status` | 任务状态，状态机 `queued → delivered → running → done | failed | timeout`（`tools/orchestrator/router.py:1-5`） |
| `from → to` | 派单方 → 接单方角色 |
| `intent` | 任务意图/动作，自由文本（示例：`implement`） |
| `pointer` | 任务指针/定位，自由文本（交流区条目标识、文件路径或 URL） |
| `idempotency_key` | 幂等键 |
| `attempts` | 尝试次数 |
| `max_tokens` / `max_minutes` | 配额上限 |
| `cost_tokens` | 已用 token |
| `created_at` / `updated_at` / `ack_at` / `completed_at` | 本地完整时间 |
| `acceptance` | 验收标准列表 |
| `artifacts` | 产物列表 |

- 详情数据来自 Tasks 列表现有快照，不额外调用 `/task`；因此不含该端点的 `messages`（`App.tsx:300,320-325`）。

### 6.3 `intent` / `pointer` / `acceptance` 口径

- 三者都是派单入参：`intent`、`pointer`、`acceptance` 由 `orchestrator_need` 传入（`tools/orchestrator/router.py:190-195`；示例见 `编排服务使用说明.md` §派单）。
- `intent`：任务要做什么，自由文本，不是受限枚举。
- `pointer`：任务定位/依据，自由文本；示例使用 `docs/local/交流区/交流区.md#P-12`。
- `acceptance`：验收标准字符串列表；worker 按 pointer + acceptance 执行。
- UI 只在 Tasks 表格展示 `intent`；`pointer`、`acceptance` 在任务详情中展示。

## 10. 数据刷新与重连

- **无轮询**：不使用 `setInterval` / `EventSource`；状态与日志均为 SSE（`sse.ts` 文档注释、源码静态检查要求）。
- `/events`：
  - `snapshot`：更新 daemon + agents，并去抖 250ms 重取 `/tasks`；
  - `heartbeat`：更新 daemon + agents，**不**重取 `/tasks`；
  - `shutdown`：标记连接关闭；
  - 断线后指数退避重连（1s 起、上限 15s、±20% 抖动），每次重连重新解析 `daemon.json`（`App.tsx:74-110`、`sse.ts:55-64,95-142`）。
- `/logs/stream`：
  - 连接时回放最后 100 行，随后跟随新增行；`[role]` 前缀并入 Console；
  - 与状态流独立重连；后端 `event: shutdown` 不写入 Console；
  - 每次重连会再次回放 100 行（当前无跨连接去重）。
- **检测 Agent** 是唯一更新 `wild`（未注册进程）的入口。
- 命令面板「刷新」只重取 `/status` + `/tasks`；「重新连接 SSE」重启两条流。

## 11. 产品边界

- **中控不杀外部进程**：`/stop` 仅对 `job_id` 非空的 daemon 托管 worker 生效；外部 Agent 返回 409 `external_agent`，不改状态、不杀进程（`tools/orchestrator/service.py:718-741`）。
- 前端：外部 Agent 显示「外部进程」，不提供停止按钮（`AgentTable.tsx:43,70-88`）。
- 不杀 MCP server、不注入、不新增退出协议；外部窗口由用户自行 Ctrl+C/关闭。
- 暂无 UI 启动托管 worker 的入口；托管 worker 仍由 daemon/CLI 创建。
- 未注册进程只读展示；P2 手动绑定未实现。
